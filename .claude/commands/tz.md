---
description: Продолжить работу по ТЗ (или уйти в режим ревизии, если работы по ТЗ нет)
---

Продолжай по ТЗ. Следуй навыку `continue-tz`: определи маршрут, прочитай README §2 → `LMS_AGENT_HANDOFF.md` → трекер активного фронта `docs/TZ_CDOPROF_MIGRATION_STATUS.md` (включая «Правила автономии» и журнал решений), возьми первую позицию очереди выполнения не в ✅ и не целиком в 🚫, запиши план фазы и сразу реализуй его — апрув владельца делегирован. Развилки решай сам по правилам автономии и записывай строкой `РМ-N`; вопросы владельцу не задавай. Закрыл позицию — бери следующую.

Если незакрытых задач нет ни в одном трекере и журнал расхождений пуст — переходи в режим ревизии по `docs/AUDIT_MODE.md`: возьми непройденный класс сверки, назови его, ищи дефекты кода.

Уточнение владельца, если оно есть, переключает маршрут: $ARGUMENTS
