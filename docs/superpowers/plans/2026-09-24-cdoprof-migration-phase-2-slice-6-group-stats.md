# Статистика посещений группы (МГ-B4.2) — Фаза 2, срез 8.8 — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking. План утверждён по поручению владельца (правила автономии ТЗ перехода).

**Goal:** В карточке группы раздел «Журнал учебных часов» становится «Статистикой посещений» (ТЗ перехода §6.3 МГ-B4.2): по каждому слушателю — последний вход, минуты в материалах (часы), прогресс, попытки и итог; выгрузка XLSX (и прежний CSV).

**Architecture:** Расширяется существующий журнал часов (ФТ-B3.4): `LearningJournalEntry` получает необязательные поля `lastLoginAt`, `progressPercent`, `attemptsCount`, `bestScore`, `maxScore`, `examPassed`, `resultCode`; `LearningHoursService` берёт прогресс из `courseProgress`, попытки и итог экзамена из `attempts`/`examResults` снимка, а последний вход — одним SQL по `iam.sessions` через необязательную `DatabaseService` (без базы поле пустое). Новая ручка `GET groups/:groupId/learning-journal.xlsx` (право `groups.read`, как у журнала) отдаёт файл через `ReportXlsxWriter`. Фронт: тот же раздел, таблица ужимается до 7 колонок (сейчас 8 — журнал 636), поминутная раскладка уходит в файл.

**Tech Stack:** NestJS, `exceljs` через `ReportXlsxWriter`, `DatabaseService.query`, `@trudskill/ui` `DataTable`, vitest.

**Spec:** `TZ_TRUDSKILL_CDOPROF_MIGRATION.md` §6.3 МГ-B4.2 («последний вход, минут в материалах (есть учёт часов ✔), прогресс, попытки; выгрузка XLSX»); ТЗ редизайна §13.2 (≤7 колонок), §7.2 (`TPL-002`, вложенных вкладок нет).

## Global Constraints

- Контракт журнала только расширяется (новые поля необязательные); URL `learning-journal` и `learning-journal.csv` не меняются, `learning-journal.xlsx` — добавляется; право — `groups.read` (журнал 341).
- SQL с буквальным `tenant_id` (сторож `tenant-scoped-reads`); зависимость от базы — необязательная, режим `ALLOW_IN_MEMORY_STATE` работает без неё.
- Таблица ≤7 колонок, одно первичное действие карточки прежнее; кнопки выгрузки — вторичные, называют результат.

## Решения (журнал РМ трекера)

- **РМ65.** «Статистика посещений» — не новая вкладка и не новый экран, а расширенный журнал часов на карточке группы (ТЗ §6.3 не включает статистику в список вкладок, а «учёт часов ✔» уже есть): те же ручки, поля добавляются; XLSX — новая ручка рядом с CSV.
- **РМ66.** «Последний вход» = последняя сессия пользователя, связанного со слушателем (`learners.linked_iam_user_id` → `iam.sessions.created_at`, одним запросом на группу); колонка `learning.learners.last_login_at` (0106) не используется — её никто не пишет, а сессии — источник правды; без связки с пользователем — «не входил».
- **РМ67.** Прогресс слушателя в группе — среднее `progressPercent` по `courseProgress` его зачисления (курсов у группы может быть несколько); попытки — все не черновые попытки по зачислению; «лучший балл» и «сдал» — из `examResults` зачисления (любой сданный итог = сдал), итог `resultCode` (8.7a) показывается тем же столбцом: «не явился» важнее балла.

## Review Focus

1. Слушатель без связанного пользователя → «не входил», а не пустая ячейка или ошибка (тест сервиса без базы и с базой).
2. Несколько курсов у группы → прогресс усредняется, а не берётся первый попавшийся (тест).
3. Черновые попытки (`draft`) не считаются попытками (тест).
4. Ручка XLSX отдаёт файл с правильным типом и именем `learning-journal-<код группы>.xlsx`, без права `groups.read` — 403 (HTTP-стаб).
5. Таблица на экране — ровно 7 колонок; раскладка минут по видам — только в файле (сторож бюджета — руками по коду; тест на число колонок в тесте раздела, если есть).
