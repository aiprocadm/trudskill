# Фаза 5 — единые правила экранов (ТЗ «Стабилизация, UX и развитие», задачи 5.1–5.7)

Дата: 2026-09-17. Основание: очередь выполнения, позиция 7. Предшественники — фазы 2, 3, 4 и 10
(§5.469–§5.482), закрытые по одной задаче на PR без отдельного плана; для фазы 5 план нужен:
семь правил трогают десятки экранов, и порядок важен.

## Как читать ТЗ фазы

Каждое правило — сначала **компонент или утилита в `@trudskill/ui`** (правило живёт один раз),
затем запись в `docs/ui/patterns.md`, затем раскатка по экранам. Сторож на каждое правило —
как в фазах 2–4: по исходникам, с подсаженными поломками. Задача = один PR ≤ 30 файлов,
зелёный `pnpm ci:check` (код выхода из файла, документы отформатированы до запуска).

Порядок задач — порядок ТЗ, с одной оговоркой: 5.6 (единый шаблон списка) собирает остатки
5.1 и 5.5 (таблицы со своими колонками «Действия», панели массовых действий), поэтому идёт
после них.

## Задача 1 — 5.1 (Э1) Один набор действий в строке таблицы

**Файлы:** `packages/ui/src/components/overflow-menu/` (новый), `packages/ui/src/components/table/row-actions.ts` (новый), `packages/ui/src/components/table/index.tsx`, `packages/ui/src/styles/foundation.ts`, `packages/ui/src/styles/tables.ts`, четыре экрана с действием «Открыть …», `apps/frontend/src/e2e/one-action-set-per-row.e2e.test.ts` (новый), `docs/ui/patterns.md` (новый).

**Задачи:**

- [x] `OverflowMenu` — меню «…» на `<details>`, опасные пункты внизу за разделителем, красным; тест.
- [x] `splitRowActions` — чистое правило: одно основное действие в строке, остальное в меню; единственное неопасное — сразу; опасное основным быть не может; тест.
- [x] `DataTable` рисует действия через правило — все 18 экранов с `rowActions` получают меню автоматически.
- [x] Экраны с «Открыть …» помечают его `primary` (документы/задачи, заявки на проверку личности, слушатели, группы).
- [x] Сторож: таблица по правилу; опасные внизу; ≤1 `primary` на экран; очередь своих колонок «Действия» (12 мест в 5 файлах) сверяется на равенство — тает в 5.6.
- [x] `docs/ui/patterns.md` — запись Э1.

**Приёмка:** на «Арендаторах платформы» в строке — только «…»; в меню «Сменить тариф», «Войти от имени», ниже за чертой — «Приостановить центр» / «Перевести в архив» красным. На «Группах» — «Открыть группу» в строке.

## Задача 2 — 5.2 (Э2) Действие соответствует состоянию объекта

**Файлы:** карточка курса (`courses-screens.tsx`: «Опубликовать» → «Снять с публикации» / «Создать новую версию»), «Мои тесты» («Продолжить» при 0 попыток), «Документы» у руководителя (пустая колонка «Действия» и «Создать шаблон» без права), сторож.

**Задачи:**

- [ ] Ревизия: список кнопок, которые показываются вхолостую (без права или не по состоянию) — сканером по `disabled`/`hasPermission` рядом с кнопками.
- [ ] Правило в пакете: кнопка получает подпись от состояния объекта (словарь «состояние → действие»), недоступное действие скрывается; проверка возможности — на сервере (ручки уже возвращают отказ), кнопка — отражение ответа.
- [ ] Сторож: у опубликованного курса нет кнопки «Опубликовать»; при 0 попыток нет «Продолжить».

**Приёмка:** критерий ТЗ 5.2 дословно.

## Задача 3 — 5.3 (Э3) Подтверждение необратимых действий

**Файлы:** `useConfirmDialog` в пакете (уже есть), экраны: «Приостановить центр», «Перевести в архив», «Отозвать лицензию», «Архивировать слушателя», «Закрыть группу», «Завершить тест»; сторож `irreversible-needs-typing` расширяется.

**Задачи:**

- [ ] Проверить каждое из шести действий: диалог называет объект и последствие, требует осознанного клика.
- [ ] Для самого тяжёлого (закрытие группы, архив центра) — ввод названия, механика «Обезличивания» переиспользуется, не копируется.
- [ ] Сторож: список необратимых действий сверяется на равенство с местами, где стоит подтверждение с объектом и последствием.

## Задача 4 — 5.4 (Э4) Опасное действие — не главная кнопка экрана

**Файлы:** карточка группы («Закрыть группу» — главная оранжевая кнопка), `PageHeader` (`primaryAction` не может быть `danger`), сторож `primary-action-budget` расширяется.

**Задачи:**

- [ ] Тип `primaryAction` в `PageHeader` не допускает опасного действия; опасное — вторичная кнопка или пункт «Ещё».
- [ ] Карточка группы: главная кнопка — конструктивная («Зачислить слушателей» / «Выдать документы»), «Закрыть группу» — в «Ещё» внизу.
- [ ] Сторож: ни один экран не отдаёт `primaryAction` с опасной подписью (словарь необратимых глаголов).

## Задача 5 — 5.5 (Э5) Панель массовых действий — липкая

**Файлы:** `BulkActionBar` в пакете (`CMP-011`), стили (липкая к низу), «Слушатели» и остальные списки с выделением, сторож `selection-has-bulk-action` расширяется.

**Задачи:**

- [ ] `BulkActionBar` прилипает к низу экрана при первом выделении; счётчик; 3–5 действий: добавить в группу, назначить курс, выгрузить, архивировать (опасное — последним, красным).
- [ ] Сторож: панель рисуется из пакета, `position: sticky/fixed` в стилях, у каждого списка с выделением ≥ 2 неопасных действия.

## Задача 6 — 5.6 (Э6) Один шаблон списка для всех списков

**Файлы:** `ListPage` (`packages/ui/src/composition/list-page.tsx`), «Группы», «Курсы», «Пользователи» и очередь `list-page-ratchet`; таблицы со своими колонками «Действия» (из очереди сторожа 5.1); `Pagination` при одной странице.

**Задачи:**

- [ ] Порядок блоков шаблона: поиск → быстрые отборы → фильтры → выбор колонок → таблица → массовые действия; «Слушатели» — эталон.
- [ ] «Группы» получают поиск и фильтры; «Пользователи» — колонку «Роль» (есть фильтр — есть колонка).
- [ ] Пагинация не показывается, когда страница одна.
- [ ] Очередь своих колонок «Действия» (5.1) переводится на `rowActions` и обнуляется.
- [ ] Сторож: `list-page-ratchet` тает до нуля; колонки соответствуют фильтрам.

## Задача 7 — 5.7 (Э7) Разбить «простыни»

**Файлы:** «Арендаторы платформы», «Документы», «Настройки» tenant_admin, карточка курса; `DetailLayout`/вкладки из пакета (`TPL-002`: один уровень вкладок).

**Задачи:**

- [ ] Каждая «простыня» режется на вкладки одного уровня или отдельные страницы; в «Настройках» левый список ведёт предсказуемо — либо всегда на страницу, либо всегда к секции.
- [ ] Сторож: у эталонных страниц ≤ 3 блоков до сгиба (`GOAL-3` уже держит панель — расширить на четыре «простыни»).

**Приёмка фазы:** чек-лист ТЗ, пункты 8 («подтверждение необратимого действия с названием объекта») и 6 («нет горизонтальной прокрутки при 1280 px») — по коду; остальное — на стенде за владельцем.
