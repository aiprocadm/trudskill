# Карточка слушателя с вкладками (МГ-C2.1) — Фаза 2, срезы 9.1–9.3 — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking. План утверждён по поручению владельца (правила автономии ТЗ перехода).

**Goal:** Карточка `/learners/:id` по ТЗ перехода §6.4 МГ-C2.1: вкладки «Личное дело · Обучение · Документы · Файлы · История», правка из карточки (уже есть — 8.12b), действия «Выслать доступ», «Лист доступов», «Обезличить» в меню «…».

**Architecture:** Разведка (§5.589): карточка — одна лента `DetailLayout` без вкладок; «Учебная история» дублирует «Обучение»; блок «Личные данные (для PDF)» печатает **полный СНИЛС** под `learners.read` (журнал 638) и мёртвую кнопку «Экспорт PDF»; ручек «файлы слушателя», «история слушателя», «выслать доступ» нет; «Лист доступов» — МГ-C4 (ждёт входа по логину); готовый механизм «личное дело одним PDF» (`GET /learners/:id/dossier.pdf`, ФТ-C2) **в интерфейсе не подключён** (журнал 641 — дрейф). Работа тремя срезами по одному PR:

- **9.1 (этот PR):** вкладки Личное дело · Обучение · Документы · История на `PageTabs` + `useTabParam` (TPL-002: один уровень вкладок, `KeyValueList` справа); «Обучение» и «Документы» — из агрегата `pdf-card`, расширенного группой, итогом и числом документов по зачислению; «История» — новая ручка `GET /learners/:id/history` (`learners.read`) без значений полей; меню «…»: «Скачать личное дело (PDF)» (подключает ФТ-C2) и «Обезличить данные» (панель обезличивания по вкладке дровера); 638 — СНИЛС в агрегате `pdf-card` маскируется, дублирующие секции и мёртвая кнопка убраны.
- **9.2:** вкладка «Файлы» — хранилище файлов слушателя (согласия, сканы) до N файлов (настройка `learnerFilesLimit`, по умолчанию 10) на модуле `files` с антивирусным гейтом.
- **9.3:** «Выслать доступ» — письмо входа слушателю по `linkedIamUserId` (тем же отправителем, что у приглашения сотрудника); «Лист доступов» остаётся за МГ-C4.

**Tech Stack:** NestJS (`LearnerPdfCardService`, `AuditService.listPage`), `@trudskill/ui` (`PageTabs`, `TabPanel`, `DetailLayout`, `DataTable`, `PageHeader.secondaryActions`), vitest, сторожа `src/e2e` (эталон MET-001 `/learners/[id]`).

**Spec:** `TZ_TRUDSKILL_CDOPROF_MIGRATION.md` §6.4 МГ-C2.1; ТЗ редизайна §7.2 TPL-002 (вложенные вкладки запрещены), §13.2 (≤7 колонок, 1 первичное действие), TXT-002 (одно имя действия везде); ТЗ «Арендная СДО» ФТ-C2 (дело слушателя).

## Global Constraints

- Права, URL и контракты не меняются; новая ручка `GET /learners/:id/history` под существующим `learners.read` (§16 ТЗ — ручки разрешены), новые поля агрегата необязательные.
- История — без `oldValues`/`newValues` (в них бывают ПДн): только «когда / кто / что / над чем».
- Вкладок один уровень; дровер правки со своими вкладками остаётся панелью, а не вложенной вкладкой карточки.

## Решения (журнал РМ трекера)

- **РМ90.** Журнал 638: агрегат `pdf-card` (только для экрана) отдаёт СНИЛС маской (`maskedSnils`) — экран уже умеет раскрывать по причине; блок «Личные данные (для PDF)» и мёртвая кнопка «Экспорт PDF» убраны. `dossier.pdf` (ФТ-C2) остаётся под `learners.read` на сервере (совместимость), в меню карточки показывается только с `learners.pii.manage`; ужесточение права ручки — решение владельца (О12).
- **РМ91.** История слушателя — новая ручка `GET /learners/:id/history` (`learners.read`), а не журнал `/audit/events` (`auth.manage_sessions` — право администратора сеансов, куратору не дать): события по слушателю (`learning.learner`, `mvp.learner`) и по его зачислениям (`learning.enrollment`, до 20 зачислений), объединённые и обрезанные до 100, без значений полей.
- **РМ92.** «Обучение» и «Документы» читаются одним агрегатом `pdf-card` (расширен `groupId`/`groupName`/`resultCode`/`documentsCount`), три запроса справочников (`/enrollments`, `/courses`, `/groups` по 100) с карточки убраны.
- **РМ93.** «Лист доступов» в меню карточки не показывается, пока нет входа по логину (МГ-C4); «Выслать доступ» — срез 9.3; «Файлы» — срез 9.2 (нужна настройка лимита и ручки файлов).

## Review Focus

1. Слушатель без зачислений и документов: вкладки показывают пустые состояния по TPL-006, история — записи о заведении.
2. Пользователь с `learners.read` без `learners.pii.manage`: меню «…» без «Обезличить» и «Скачать личное дело», СНИЛС маской, история видна.
3. Чужой слушатель (другой центр): 404, без призрачной карточки (`RecordNotFound`).
4. `?tab=history` в адресе открывает вкладку сразу; неизвестный `tab` → первая.
5. Отказ ручки истории не ломает остальные вкладки — ошибка внутри вкладки.
