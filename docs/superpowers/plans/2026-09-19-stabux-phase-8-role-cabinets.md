# Фаза 8 — кабинеты по ролям (ТЗ «Стабилизация, UX и развитие», задачи 8.1–8.4)

**Дата:** 2026-09-19. **Очередь:** позиция 10. Предыдущая позиция (фазы 11 и 12) закрыта.

## Что говорит ТЗ

У каждой роли свой кабинет, и сейчас они перепутаны: администратор платформы видит работу внутри
центра, руководитель попадает сразу в «Группы» и видит почти полное админское меню, методист видит
подписание НЭП и госвыгрузки. Кабинет, показывающий чужую работу, — это не «лишние пункты», а
ловушки: человек жмёт и получает отказ.

## Порядок работы: четыре среза, каждый — отдельный обратимый PR

- [x] Убрать работу внутри центра: курсы, слушатели, группы, заказы, документы, комиссии.
- [x] Оставить: арендаторы, тарифы, счета, лицензии, здоровье платформы, аудит, эксплуатация.
- [x] «Войти от имени» — механизм есть и сделан правильно (с записью в аудит), сохранить.
- [ ] Панель: центры по статусам, у кого заканчивается оплата, где встала очередь задач.

### Срез 4 — 8.4 Кабинет методиста

Срез разделён на две части: дерево с перетаскиванием требует ручек перестановки на сервере,
которых нет, — это отдельный обратимый шаг.

**Часть 1 (PR #757):**

- [x] Карточка курса на вкладках: Параметры · Программа · Аттестация · Документы.
- [x] Кнопка «Посмотреть глазами слушателя»: без неё методист не может проверить свою работу.
- [x] Убрать из его меню чужое: НЭП, переаттестацию, госвыгрузки.

**Часть 2 (PR #758):**

- [x] «Программа» — дерево «модуль → материалы», а не два независимых блока с повторным выбором
      модуля в выпадающем списке.
- [x] Перестановка модулей и материалов: ручки на сервере (порядок задаётся списком целиком,
      а не сдвигом по одному) + кнопки «вверх/вниз».

Отклонение от плана: вместо перетаскивания мышью сделаны кнопки «вверх»/«вниз». Причина —
перетаскивание недоступно с клавиатуры и ненадёжно на телефоне, то есть оно не запасной
способ, а наоборот: кнопки работают везде, а перетаскивание — нет. Порядок при этом уходит
одним и тем же способом (списком целиком), поэтому перетаскивание можно добавить позже, не
трогая сервер.

## Общие правила фазы

- Срез = один PR = один обратимый шаг, ≤30 файлов, зелёный `pnpm ci:check`.
- **Состав меню роли меняется только вместе со снимком `role-menu-composition`** — он и есть
  фиксация того, что видит каждая роль.
- Права берутся из живой `iam.role_permissions`, а не из названия роли и не из текста ТЗ.
- Каждый срез заканчивается сторожем, проверенным подсаженными поломками в обе стороны.
