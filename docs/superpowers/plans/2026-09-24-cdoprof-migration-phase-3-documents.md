## Решения (журнал РМ трекера)

- **РМ123.** Виды документов — каталогом в коде (14 системных видов §9.1), без таблицы: в MVP центр не заводит своих видов; «вид» — строка у привязки, строки набора, задачи и документа; вид обязан подходить шаблону по типу движка.
- **РМ124.** Решения, которые ТЗ оставило владельцу, принимаются по умолчанию (владелец может поменять настройкой): у пяти видов приказов — общий счётчик центра; серия удостоверения — свободная строка курса/группы (пусто по умолчанию); разряд — у слушателя в «Номерах удостоверений»; «требовать согласие на ПДн перед выпуском» — выключено по умолчанию; начальные значения счётчиков — вручную до переноса (Фаза 4, О1/О2).

## Review Focus

1. Выпуск по набору курса без вида — как раньше (вид необязателен).
2. Удостоверение на шаблоне приказа — отказ с названием шаблона и вида.
3. Документ, выпущенный по строке набора с видом, в книге выдачи и проекции несёт вид (`kind_code`).
4. Номер приказа = код группы у двух групп с одинаковым кодом — невозможно (код группы уникален), у протокола и приказа одной группы — разрешено после 19.x.
