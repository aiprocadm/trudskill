# Единые правила экранов

Требование ТЗ «Стабилизация, UX и развитие», **фаза 5**: «каждое правило оформляется как компонент/утилита в `@trudskill/ui` + запись в `docs/ui/patterns.md`, а затем раскатывается по экранам». Здесь — по одной записи на правило: что оно значит для человека, каким компонентом держится, какой сторож не даст его нарушить. Канон формы — [ТЗ редизайна](../TZ_UI_REDESIGN_TRUDSKILL.md) (`CMP-*`, `TPL-*`); тексты — [`tone-of-voice.md`](./tone-of-voice.md).

## Э1 · Один набор действий в строке таблицы

**Для человека.** В строке реестра стоит одно основное действие — обычно «Открыть». Всё остальное — в меню «…». Опасные действия («Приостановить центр», «Архивировать») — в этом меню внизу, отдельной секцией, красным: до них нельзя дотянуться случайно, целясь в соседний пункт. Четыре подчёркнутые ссылки подряд — так больше не бывает.

**В коде.** `DataTable` принимает `rowActions={(row) => RowAction[]}`; раскладку делает `splitRowActions` (`packages/ui/src/components/table/row-actions.ts`), меню рисует `OverflowMenu` (`packages/ui/src/components/overflow-menu/`). Экран лишь помечает основное действие:

```ts
rowActions={(row) => [
  { label: 'Открыть группу', primary: true, onSelect: () => open(row) },
  { label: 'Сменить тариф', onSelect: () => changePlan(row) },
  { label: 'Закрыть группу', danger: true, onSelect: () => close(row) }
]}
```

- `primary` — не больше одного; опасное действие основным быть не может.
- Единственное неопасное действие показывается сразу: меню из одного пункта — лишний клик.
- Единственное опасное действие — только через меню.
- На телефоне (≤480px) меню «…» — кнопка внизу карточки во всю строку (`CMP-001`).

**Не так.** Своя колонка `{ title: 'Действия', render: (row) => <button…> }` — кнопки мимо правила. Такие таблицы стоят в очереди сторожа и переводятся на `rowActions` в 5.6 (единый шаблон списка).

**Сторож.** `apps/frontend/src/e2e/one-action-set-per-row.e2e.test.ts`: таблица пакета раскладывает действия по правилу; опасные — внизу за разделителем; на экране не больше одного `primary`; очередь своих колонок «Действия» не растёт.
